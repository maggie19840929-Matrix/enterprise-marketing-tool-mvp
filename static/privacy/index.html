隐私政策

我们只收集生成建议所需的信息

本政策适用于你访问和使用获客罗盘时涉及的信息处理活动。我们按照合法、正当、必要和诚信原则处理信息，只收集实现内容建议、发布效果记录和下一轮优化所需的信息。

一、服务主体与联系方式

服务提供方：南京尚下联信息科技有限公司。

如需咨询、投诉、申请更正或删除信息，请发送邮件至 contact@fpmatrix.cn。我们将在收到完整必要信息后尽快处理。

二、我们可能收集的信息

  • 你主动填写的业务信息：行业/业务、目标、目标客户、平台偏好、当前问题、产品或服务、服务区域、素材说明、客户常见顾虑等。
  • 你主动记录的发布效果：发布链接、发布时间、曝光/浏览、互动、咨询人数、观察备注等。
  • 设备和使用信息：浏览器本地存储状态、访问路径、接口调用时间、错误日志和必要的安全审计记录。
  • 模型生成相关信息：为生成内容建议，系统会把你填写的必要业务信息提交给后端模型调用链路；API Key 不会下发到浏览器。

三、我们如何使用信息

  • 生成内容方向、本轮发布计划、平台建议和下一轮优化建议。
  • 保存你的项目状态，便于你刷新页面后继续查看、记录或调整。
  • 在启用云端同步时，让团队在内部端查看项目进展、排查问题和提供服务支持。
  • 改进内容建议质量、排查技术故障、维护服务安全和履行法律法规要求。

四、本地存储与云端同步

获客罗盘会使用浏览器本地存储保存你在当前浏览器中的项目状态。部分项目数据会同步到云端，用于跨页面恢复、内部服务支持和持续优化。你可以通过清空浏览器数据删除本地记录；如需删除云端项目数据，可通过 contact@fpmatrix.cn 联系我们处理。

五、第三方服务与模型调用

为生成内容建议，我们可能通过后端调用合规可用的文本模型服务。模型服务仅接收生成建议所需的业务上下文，不应包含身份证号、银行卡号、精确住址、健康病历、未成年人敏感信息等无关敏感信息。我们不会在前端暴露模型 API Key，也不会让模型自动登录、自动发帖、自动评论或自动私信。

六、信息共享、转让与公开披露

除为实现服务所必需、获得你的授权、履行法律法规要求或维护安全与合法权益外，我们不会向无关第三方出售或公开披露你的信息。如涉及委托处理或第三方服务，我们会要求相关方按照本政策和必要安全要求处理信息。

七、你的权利

你可以依法申请查阅、复制、更正、补充、删除你的相关信息，也可以撤回授权或停止使用服务。为保障信息安全，我们可能需要验证你的身份或项目归属后再处理相关请求。

你可以在隐私设置中关闭个性化推荐/推送。关闭后，我们将不再基于你的个人偏好、历史行为或用户画像提供个性化推荐或推送。

八、未成年人和敏感信息提示

本产品主要面向企业主、商家和团队人员。请不要填写未成年人个人敏感信息、身份证号、银行卡号、精确住址、医疗病历等与内容建议无关的信息。若你的业务涉及未成年人、医疗健康、金融、教育等敏感场景，请在发布前进行更严格的人工审核。

九、政策更新

我们可能因产品功能、法律法规或服务方式变化更新本政策。重要变更会在页面中提示。继续使用服务，即表示你已阅读并理解更新后的政策。
