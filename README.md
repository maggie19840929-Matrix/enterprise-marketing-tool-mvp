# 企业营销工具｜轻量级 Web 业务管理系统 MVP v0.1

> 面向赵娜/匡总/客户演示的轻量级业务管理系统基础包。目标不是先做“大而全系统”，而是先把客户线索、需求、功能、页面、数据回流这几件事结构化，方便人类讨论、演示、打分和后续开发。

## 当前交付

1. `01_PRD_轻量级业务管理系统.md`：产品范围、角色、页面、MVP边界
2. `02_数据库字段设计.md`：后台数据库表结构与字段说明
3. `03_前端页面清单与交互.md`：前端页面、用户流程、演示路径
4. `04_赵娜沟通版说明.md`：给赵娜看的非技术说明
5. `schema.sql`：可直接建 SQLite/PostgreSQL 原型库的基础 SQL
6. `seed_data.json`：演示数据
7. `demo/index.html`：静态前端演示页，可浏览器直接打开

## MVP 只做 5 个核心模块

- 客户/线索管理
- 需求/痛点记录
- 跟进任务管理
- 营销内容/活动记录
- 数据回流与复盘

## 暂不做

- 不做复杂 CRM/ERP
- 不做财务/库存/审批
- 不做自动群发/触达客户
- 不做复杂权限体系
- 不做多租户商业化版本

## 下一步建议

先让赵娜和匡总围绕飞书表格打分、补字段、删功能。确认 3-5 个真实客户场景后，再进入代码开发。
